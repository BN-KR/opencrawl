# OpenCrawl Project Memory

## 2026-09-01 — Initial standalone crawler

- OpenCrawl is an independent Playwright site-inspiration crawler at `C:\opencrawl`.
- `crawler.js` renders same-host pages, scrolls to trigger lazy content, downloads common assets, rewrites local references, and writes `crawl-report.json`.
- The project includes a dependency-free branded landing/dashboard in `index.html`.
- Visual identity: near-black background, white typography, muted gray copy, and mint green `#20f39c`.
- Production Vercel deployment is intentionally pending the owner’s green light.
